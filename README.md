# Operation: Success — Exam Motivation Page

A mobile-friendly, single-page encouragement website for your little brother.

## Personalize it first
Open `index.html` in a text editor and search for:
- `Your big brother` / `I'm already proud of you`
- `Your next chapter` and the encouragement paragraphs
- The AOT quote cards, if you want to swap the quote wording

The current artwork is an original CSS/SVG anime-inspired illustration rather than copied screenshots. The Demon Slayer card links to the official Crunchyroll episode page for “Set Your Heart Ablaze”; it does not host or redistribute the anime clip.

## Preview locally
Double-click `index.html`. It should open in your browser. Internet is needed only for the external streaming link.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `little-brother-success-card`.
2. Upload `index.html` and `README.md` from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then press **Save**.
6. Wait a minute or two. GitHub will show a website address like `https://YOUR-USERNAME.github.io/little-brother-success-card/`.
7. Open that address on your phone to test it, then send it to him.

No build tools or frameworks needed. It is a static site.
